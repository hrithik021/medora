# Medora1 — UAE Secondary Care Hospital Network

A Tesla.com-inspired web presence for **Medora1**, a next-generation secondary-care hospital network in the UAE, built in partnership with Apollo Hospitals in Dubai Investment Park.

## Tech Stack
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Lucide React Icons**

## Features
- Tesla-style full-bleed hero with Dubai skyline
- Medora1 Intelligence AI assistant (domain-aware, UAE-specific)
- UAE Network Map section (Tesla "Find Your Charge" layout)
- Multi-page App Router: `/hospitals`, `/medora-os`, `/stakeholders`, `/leadership`, `/contact`
- Interactive modals: AI chat, DIP tour booking, OS blueprint, founder dossiers
- Floating pill bar, white Tesla theme, M1 favicon

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
